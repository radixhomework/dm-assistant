# Places

*World → Geography*

## Fields

1. **Illustration** — image of the place
2. **Type** — one value among: Intangible place, Locality, City
3. **Leaders** — characters and entities leading the place
4. **Population** — number of inhabitants
5. **Public description** — player-readable description of the place
6. **Private description** — secrets and details of the place
7. **Nations** — nations associated with the place
8. **Characters** — characters and entities associated with the place
9. **Events** — events associated with the place
