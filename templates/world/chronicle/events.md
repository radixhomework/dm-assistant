# Events

*World → Chronicle*

## Fields

1. **Illustration** — image of the event
2. **Start** — start date (world calendar, possibly partial: year only)
3. **End** — end date; when present, the event is a period
4. **Recurrence** — repeat frequency (every x weeks, x months or x years), anchored on the start date
5. **Origin** — place of origin of the event (single reference to a Place)
6. **Public description** — description of the event for the players
7. **Private description** — secrets and details of the event
8. **Geography** — places associated with the event
9. **Characters** — characters and entities associated with the event
10. **Events** — other associated events (self-reference)
