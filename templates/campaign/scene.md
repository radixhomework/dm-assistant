# Scene

*Campaign*

## Fields

1. **Illustration** — image of the scene
2. **Play status** — game status: not played, in progress, played
3. **Order** — position of the scene in the chapter's play order
4. **DM summary** — scene summary for the DM
5. **Running notes** — multi-block running prose: what can be read to players or paraphrased, DM mechanics, attention points, images, tables…
6. **Chapter** — the parent chapter (single reference)
